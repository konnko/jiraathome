# jiraathome

Простенький self-hosted канбан для небольшой команды: поднимаешь на своём сервере,
задаёшь общий пароль и пользуешься. Без регистрации и отдельных аккаунтов.

- Четыре столбца: Бэклог → Исследуется → Делается → Готово.
- Карточки с Markdown-редактором Milkdown, комментариями и перетаскиванием.
- Обновления доски в реальном времени.
- Общий файл с совместным редактированием и списком присутствующих.
- SQLite: отдельный сервер базы данных не нужен.
- Время в интерфейсе — в часовом поясе браузера пользователя.

Приложение написано на Elixir, Phoenix LiveView и SQLite.

## Запуск через Docker

Нужны Docker и Docker Compose.

```sh
git clone https://github.com/Konnko/jiraathome.git
cd jiraathome
cp .env.example .env
openssl rand -base64 48
```

Открой `.env`, задай свой пароль в `APP_PASSWORD`, а результат последней команды
вставь в `SECRET_KEY_BASE`:

```dotenv
APP_PASSWORD=your-long-password
SECRET_KEY_BASE=paste-generated-secret-here
PHX_HOST=localhost
PHX_SCHEME=http
```

Затем запусти:

```sh
docker compose up -d --build
```

Открой http://localhost:4000 и введи имя и заданный пароль.
Миграции базы выполняются автоматически. Данные хранятся в Docker volume `data`.
`docker compose down` сохраняет данные; `docker compose down -v` удаляет их.

Compose публикует порт только на `127.0.0.1`. Для доступа через интернет поставь
перед приложением HTTPS-прокси с поддержкой WebSocket, задай свой домен в `PHX_HOST`
и `PHX_SCHEME=https`.

## Как установить или поменять пароль

Пароль общий для всех пользователей и задаётся переменной `APP_PASSWORD`.
В Docker измени её в `.env` и пересоздай контейнер:

```sh
docker compose up -d --force-recreate
```

При запуске из исходников передай переменную при старте:

```sh
APP_PASSWORD='your-long-password' mix phx.server
```

В development без этой переменной используется пароль `dev`.
В production пароль обязателен. Файл `.env` читает Docker Compose;
`mix phx.server` автоматически его не загружает.

Имя при входе используется для подписей карточек, комментариев и правок.
У всех одинаковые права. Смена пароля действует на новые входы: уже открытые
сессии сохраняются. Чтобы сбросить все сессии, поменяй также `SECRET_KEY_BASE`
и пересоздай контейнер. Обычно этот ключ следует сохранять между перезапусками.
Не добавляй `.env` и базу данных в Git.

## Локальная разработка

Нужны Elixir 1.19+, Erlang/OTP 28+ и Node.js 22+ с npm.

```sh
mix setup
APP_PASSWORD='your-long-password' mix phx.server
```

Приложение доступно на http://localhost:4001. База — `jiraathome_dev.db`.
После обновления исходников выполни `mix ecto.migrate`.

Проверки:

```sh
mix precommit
```

В development доступен Tidewave по адресу http://localhost:4001/tidewave/mcp.

## Общий файл

На странице `/file` используется Milkdown Crepe и Yjs. Изменения отправляются
через WebSocket Phoenix LiveView после паузы во вводе в 1 секунду;
сервер последовательно сохраняет их в SQLite. Отдельный сервер Yjs и P2P не нужны.

При потере связи черновик хранится в текущей вкладке и отправляется после
переподключения. Перед закрытием вкладки дождись статуса «Все изменения сохранены».
Описание карточки сохраняется только кнопкой «Сохранить», без совместного редактирования.
